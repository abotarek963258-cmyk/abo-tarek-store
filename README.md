# أبو طارق للأدوات المنزلية

موقع عربي RTL ثابت (HTML/CSS/JavaScript) جاهز للنشر على GitHub Pages.

## الملفات
- `index.html` الصفحة الرئيسية
- `style.css` التصميم
- `script.js` المنتجات والبحث والفلاتر والنافذة المنبثقة

## النشر
يمكن نشر الملفات مباشرة على GitHub Pages من مستودع عام على GitHub Free.
